# RevoShop Database

Proyek ini adalah database sederhana untuk sistem e-commerce.  
Tabel utama: users, orders, order_items, products, categories.

## Struktur File
- schema.sql → definisi tabel
- seed.sql → data awal
- queries.sql → contoh query
- ERD_revoshop.png → diagram relasi
- README.md → dokumentasi
- .gitignore → filter file sampah

## Cara Setup
1. Buat database `revoshop_db`
2. Jalankan `schema.sql`
3. Jalankan `seed.sql`
4. Jalankan `queries.sql`
